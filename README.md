# Loan Processing Process Improvement — BPMN As-Is / To-Be Project

## Overview

This Business Process Management project analyzes and redesigns a loan scheduling and processing workflow for a fictitious bank experiencing major operational delays and coordination failures.

The engagement applies structured process analysis and future-state modeling to improve efficiency and control.

## Objectives

* Document the current (As-Is) loan processing workflow
* Identify bottlenecks and failure points
* Design an optimized future (To-Be) process
* Provide rationale for process changes

## Artifacts Included

* As-Is process diagrams
* To-Be process diagrams
* Gap analysis notes
* Improvement recommendations

## Methods Used

* Process decomposition
* Workflow mapping
* Bottleneck analysis
* Control point redesign

## Value Demonstrated

Shows capability in process modeling, operational analysis, and structured process improvement design.
